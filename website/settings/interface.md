# 界面设置

配置应用的外观和行为。

## 启动默认页

设置应用启动后默认显示的页面。

可选页面：

| 页面 | 说明 |
|------|------|
| 首页 | 每日推荐、新专辑等 |
| 歌单 | 歌单列表 |
| 历史 | 播放历史 |
| 本地音乐 | 本地音乐列表 |
| 我的 | 个人中心 |
| 设置 | 设置页面 |

::: tip
选择后下次打开应用自动跳转到该页面。
:::

## 主题模式

- **跟随系统** — 根据系统深色/浅色模式自动切换
- **深色模式** — 强制深色
- **浅色模式** — 强制浅色

## 动画速度

调节界面动画的播放速度（0.5x ~ 2x）。

- 较快：界面响应更迅速
- 较慢：过渡更柔和
- 推荐默认 1x

## 字体

全局字体设置。

::: warning
字体导入功能已迁移至播放器样式的自定义效果中，每种样式可单独设置字体。
详见 [字体导入](/features/font-import)。
:::
