# 字体导入

支持导入自定义 `.ttf` / `.otf` 字体文件用于歌词显示。

## 导入步骤

1. 在全屏播放器中点击右上角设置按钮
2. 选择一个非默认样式
3. 在「自定义效果」面板中点击「导入字体 (.ttf)」按钮
4. 系统文件选择器打开，选择 `.ttf` 或 `.otf` 文件
5. 字体导入成功后，文件名显示在按钮旁边

## 生效范围

- 字体导入**仅对当前选中的样式生效**
- 切换到其他样式后需要重新导入字体
- 每个样式可以导入不同的字体

## 技术原理

1. 字体文件读取为 `ArrayBuffer` → `base64` 编码
2. 动态注入 `@font-face` CSS 规则
3. 应用到当前样式对应的歌词元素

```css
@font-face {
  font-family: 'UserFont-stage';
  src: url(data:font/ttf;base64,AAAA...);
}
```

## 注意事项

::: warning 字体版权声明
- 部分字体为商业付费字体（如方正、汉仪等），未经授权使用可能侵权
- 用户应确保所导入的字体已获得合法授权
- 字体文件仅存储在设备本地，不会上传
- 因使用侵权字体引发的纠纷由用户自行承担

详见 [用户协议](https://github.com/cang-dot/zephyrus-player-android/blob/main/用户协议.md) 第三条。
:::

- 字体文件过大（>1MB）可能导致 localStorage 溢出
- 建议使用精简版字体（仅包含常用字符）
- 清除应用数据可删除已导入的字体
