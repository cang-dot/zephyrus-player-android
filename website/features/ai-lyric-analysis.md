# AI 歌词分析

AI 驱动的歌词隐喻和修辞手法分析。

## 使用方法

1. 在全屏播放器中点击右上角设置按钮
2. 找到「歌词解析」区域
3. 点击「开始分析」按钮
4. 等待 AI 分析（约 10-30 秒）
5. 分析结果以 Markdown 格式显示

## 分析内容

AI 会分析当前歌词中的：

- **隐喻** — 比喻、暗喻
- **象征** — 象征手法
- **修辞** — 排比、对偶、夸张等
- **意象** — 歌词中的意象分析

## 配置

需要在设置中配置 AI API：

1. 打开 **设置** → 找到 AI 相关设置
2. 选择 AI 服务商
3. 输入 API Key
4. 选择模型

## 缓存

- 分析结果会缓存，重复播放同一首歌不会重新分析
- 缓存存储在本地，清除应用数据可清除缓存

::: tip
AI 分析需要网络连接和有效的 API Key，否则会显示错误信息。
:::
