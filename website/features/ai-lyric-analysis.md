# AI 歌词分析

播放界面 → 设置 → **歌词解析**可以分析当前歌曲的隐喻、意象、叙事和修辞，结果以 Markdown 流式渲染，可一键复制纯文本。

从 v1.3.5 起，AI 功能改用**自带密钥（BYOK）**模式：客户端直连你选择的服务商，不再经过云端网关，也无需积分与网易云验证。

## 配置密钥

1. 前往 [免费 AI 密钥领取指南](/guide/free-api-keys) 领取一个密钥（智谱 GLM-4-Flash 永久免费，OpenRouter 有大量 `:free` 模型，Pollinations 甚至无需密钥）。
2. 打开 **设置 → 基础设置 → 歌词 AI 解析**，选择服务商、粘贴密钥，模型下拉会给出该服务商的建议模型（可自由输入）。
3. 打开播放界面设置，展开「歌词解析」，点击**开始分析**。

::: tip 已有旧配置？
v1.3.5 之前的网关配置会自动迁移到智谱免费档（`glm-4-flash`），重新填一次密钥即可使用。
:::

## 分析内容

分析需要的数据：

- 歌曲名称、歌手和专辑介绍；
- 当前歌词文本。

请求由客户端直连你选择的服务商，密钥只保存在设备本地。部分免费模型可能将请求用于服务改进，请勿在歌词或自定义提示中加入账号凭据等敏感信息。

## 常见问题

### 提示「需要 API 密钥」

所选服务商需要密钥而密钥为空。按上方指引领取并粘贴即可。

### 401 / 403 鉴权失败

密钥填错或已过期；OpenRouter 的密钥以 `sk-or-` 开头，智谱以一串十六进制/UUID 形式呈现，注意不要混用。

### 模型名报错（model not found）

模型 id 输入有误。优先使用模型下拉里的建议条目；自定义模型 id 以服务商文档为准。

### 一直显示正在连接

分析区会轮换显示「正在品鉴、正在解析、正在聆听…」和已运行时间。免费模型限流时首段等待可能变长；连续失败可切换其它服务商。

::: tip
已完成的结果保存在本地缓存中。歌词内容、歌词版本或模型改变后会重新生成。
:::

## AI 能力的更多玩法

同一份密钥配置还驱动：

- **AI 私人 FM**（首页横卡）：按你的口味推荐歌曲直接开播；
- **AI 歌单**（歌单页顶栏）：基于最近收藏的风格联想、或基于关注音乐人生成歌单；
- **智能均衡器**（播放设置）：根据当前歌曲的频谱特征自动调音。
