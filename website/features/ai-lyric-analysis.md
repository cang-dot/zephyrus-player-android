# AI 歌词分析

Zephyrus 1.2.5 可以从播放设置中分析当前歌曲的隐喻、意象、叙事和修辞。分析由 Zephyrus 云端网关转发，不需要在应用中填写模型厂商的 API Key。

## 开始分析

1. 使用网易云账号登录，或在“设置 > 基础设置 > Cookie 管理”中填写有效的 `MUSIC_U` Cookie。
2. 在基础设置的“歌词 AI 分析”中填写共享访问 Token，并验证网易云账号。
3. 打开播放界面设置，展开“歌词解析”。
4. 从下拉菜单选择模型，点击“开始分析”。

模型返回内容会逐段显示并实时渲染 Markdown。长篇结果可以在独立滚动区域内阅读，也可以一键复制为不含 Markdown 标记的纯文本。

## 模型与积分

每个账号每天获得 100 积分，不同模型按倍率扣除。下拉菜单会显示模型名称和倍率；当天剩余积分可在基础设置中查看。

如果积分不足，可以改用倍率更低的模型，或等待次日额度恢复。相同歌曲、歌词版本和模型的缓存命中不会重复扣费。

## 数据与隐私

应用只向所选模型发送完成分析所需的数据：

- 歌曲名称、歌手和专辑；
- 当前歌词文本；
- 生成分析所需的系统提示。

网易云 Cookie 仅用于创建短期 AI 会话，不会作为提示词发送给模型。部分免费模型可能将请求用于服务改进，选择模型前请阅读应用内的隐私提示，不要在歌词或自定义提示中加入账号凭据和其他敏感信息。

## 常见状态

### AI 会话已过期

回到基础设置重新验证网易云账号。若刚验证仍提示过期，请确认设备时间准确，并检查共享访问 Token 是否与服务器一致。

### AI 上游服务不可用

所选模型可能限流、维护或暂时离线。切换其他模型后重试；如果所有模型均不可用，请稍后再试。

### 一直显示正在连接

分析区会轮换显示“正在品鉴、正在解析、正在聆听、正在分析、正在思考、正在整理”和已运行时间。首段内容到达后会立即开始流式显示；网络较慢时首段等待可能更长。

::: tip
已完成的结果保存在本地缓存中。歌词内容、歌词版本或模型改变后会重新生成。
:::
