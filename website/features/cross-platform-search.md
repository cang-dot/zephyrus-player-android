# 跨平台搜索

搜索网易云 + QQ音乐 + 咪咕 + 酷狗 + 酷我，自动去重合并。

## 工作原理

```
搜索关键词
  → 网易云 API 搜索（主）
  → 跨平台搜索（异步补充）
    → QQ音乐 / 咪咕 / 酷狗 / 酷我 / JOOX
    → 与网易云结果去重
    → 合并到搜索结果列表
```

- 网易云结果先展示，跨平台结果异步合并进来
- 搜索时显示「正在搜索其他音源...」加载提示
- 完成后每首歌标注来源（网易云 / JOOX / QQ 等）

## 来源筛选

搜索完成后，类型标签下方出现来源筛选 chips：

- **全部** — 显示所有结果
- **网易云** — 仅显示网易云音源
- **JOOX** — 仅显示 JOOX（QQ音乐国际版）音源
- **QQ音乐** — 仅显示 QQ音乐音源
- 等等...

点击 chip 即可筛选。

## 来源标签

每首歌曲右上角显示来源角标：

| 标签 | 颜色 | 含义 |
|------|------|------|
| 网易云 | 绿色 | 网易云直连可播 |
| 网易云VIP | 黄色 | 需 VIP |
| JOOX | 青色 | JOOX 音源 |
| QQ音乐 | 蓝色 | QQ音乐音源 |
| 咪咕 | 橙色 | 咪咕音源 |
| 酷狗 | 蓝色 | 酷狗音源 |
| 酷我 | 紫色 | 酷我音源 |

## 配置

### Cookie 配置

跨平台搜索的效果取决于是否配置了各平台的 Cookie：

- 未配置 Cookie → 仅能搜索到公开内容
- 配置 Cookie → 可解锁 VIP 内容、更高音质

详见 [Cookie 获取](/cookie/netease)。

### 默认行为

- **默认关闭酷我**（URL 解析不稳定），可在设置中开启
- JOOX 优先（覆盖 QQ 独占内容且 URL 解析稳定）
- 每平台默认返回 20 条结果
