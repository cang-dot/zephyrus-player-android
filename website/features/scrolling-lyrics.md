# 滚动歌词

滚动歌词使用统一逐字时间轴。当前主句居中对齐，长音节可以产生轻微发光与抬起效果，翻译、罗马音和 TTML 辅助声部按配置显示。

## 逐字进度

TTML、YRC 和 QRC 会保留数据源提供的分词，不会把英文单词二次拆字。普通 LRC 没有分词时间时显示整句进度。

拖动进度条后，歌词状态会立即按新时间重新计算；切歌时会清理上一首的 TTML 和动画 key。

## 背景词与对唱

只有 TTML 能表达背景与对唱声部。

- 背景词在主歌词下方显示完整句子。
- 背景词内部仍有逐字卡拉 OK 进度，不会每次只显示一个字。
- 对唱词使用与主歌词相同的排版，颜色为浅色并透入少量歌曲主题色。
- 不额外给背景词自动添加括号，原文件中的标点会原样显示。

## 翻译与罗马音

“显示翻译”默认开启，“显示罗马音”默认关闭。两者按时间戳优先精确匹配，再在 300 ms 内匹配最近行；仅当行数一致时才按索引回退。

## 点击与手动滚动

手动滚动时自动跟随会短暂停止。点击某句可以跳转到对应时间，等待后重新回到当前播放行。

## 符号异常

如果 `！`、`（`、`）` 或 `￥` 被替换，先确认歌词文件编码为 UTF-8。当前解析器不会主动替换这些符号，也不会为 TTML 背景声部添加括号。仍能复现时，请在 Issue 中提供歌曲平台、歌曲 ID、歌词格式和出错片段，不要上传完整受版权保护歌词。
