# 滚动歌词

全屏滚动歌词模式，提供完整的歌词浏览体验。

## 进入方式

在全屏播放器中**双击屏幕**进入滚动歌词模式。

## 功能

### 自动滚动

歌词自动跟随播放进度滚动，当前句居中显示，上下有渐变遮罩。

### 手动滚动

- 手动拖动后，自动滚动暂停 3 秒
- 拖动时右侧显示**时间指示器**，显示当前可视区域对应的时间
- 3 秒后恢复自动滚动

### 点击跳转

- 点击歌词文字 → 跳转到该句歌词对应的时间
- 点击时间指示器 → 跳转到指示器显示的时间
- 点击空白区域 → 退出滚动歌词模式

### 歌词样式

- 当前句：高亮放大
- 非当前句：半透明
- 逐字歌词：每个字随播放进度高亮（需歌曲支持逐字歌词）

## 配置

在播放设置中可配置：

- **显示翻译** — 歌词下方显示翻译
- **逐字歌词** — 逐字高亮（部分歌曲支持）
- **歌词颜色** — 歌词颜色主题
