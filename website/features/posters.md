# 歌词海报

长按歌曲进入详情后可以生成歌词海报。所有布局都在本机 Canvas 中渲染，分享前可以调整字体、字重、颜色、二维码和水印。

## 默认布局

保留撕纸和沉浸式布局，适合以封面和单段歌词为主的快速分享。

## 演出档案

演出档案使用黑白或低饱和封面、高饱和书法标题、歌手与专辑信息块，再把大字号歌词放在下半区。适合现场、乐队与叙事性较强的内容。

可调项目包括字体、字重、强调色、图像滤镜、二维码和水印。

## 印章巡演

印章巡演使用高对比图像、竖向或错位标题、中央作者印章和底部巡演信息。日期自动读取生成海报当天，不需要手动填写地点。

作者印章会按名字长度智能分割：短名字保持紧凑，较长名字分成视觉均衡的多行。印章边缘使用不规则缺口模拟真实印泥，不依赖外部 SVG 请求。

强调色可以跟随歌曲主题色，也可以改为自定义颜色。

## 字体

海报与播放器共享字体列表。自定义字体支持字重调整，但实际粗细仍受字体文件提供的字形影响。导入字体前请确认许可证允许分享生成图片。
