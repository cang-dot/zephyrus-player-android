# 定时关闭

设定倒计时，到时间自动暂停播放。

## 使用方法

1. 在全屏播放器中点击右上角设置按钮
2. 找到「定时关闭」区域
3. 选择预设时间或自定义时间

## 预设时间

| 选项 | 说明 |
|------|------|
| 15 分钟 | 适合短时间收听 |
| 30 分钟 | 适合日常使用 |
| 60 分钟 | 适合长时间收听 |
| 90 分钟 | 适合睡前使用 |

## 自定义时间

也可以手动输入分钟数（1 ~ 999 分钟）。

## 倒计时显示

设定后，定时区域显示剩余时间倒计时。

## 取消

点击「取消」按钮可随时取消定时关闭。

::: tip 睡眠使用
定时关闭特别适合睡前听音乐，设定 30 分钟后自动停止播放，不用担心忘记关。
:::
