# 高潮标注

高潮区间用于驱动主题色、CRT、重点字、逐字砸下、错落和烟雾暗角等效果。Zephyrus 会在切歌时从公共播放层加载当前歌曲的高潮数据，各播放器样式共享同一份时间轴。

## 数据来源

- 用户可以在播放器中手动标注高潮区间。
- 已知歌曲可读取服务端保存的公共标注。
- 上传前会保留本地标注，网络失败不会阻塞播放。
- 未取得高潮数据时播放器继续工作，只是不触发高潮限定效果。

## 进度条

高潮区间会显示在移动播放器进度条上。拖动、暂停和切歌都会重新计算当前是否位于高潮区间，避免样式之间各自请求造成状态不同步。

## 与逐字歌词的关系

高潮区间只决定效果是否触发，不改变歌词来源。逐字砸下和错落需要 TTML、YRC 或 QRC；没有逐字歌词时保留当前样式的普通歌词展示。

TTML 间奏和尾奏状态不要求处于高潮区间。当当前主歌词分词已经结束，距离下一条主歌词至少 15 秒，或后续已无主歌词时，大字样式会显示半透明封面和歌曲名。
