# 高潮检测

实时检测歌曲的高潮段落和鼓点，驱动视觉效果。

## 工作原理

### 高潮段落检测

- 基于 RMS（均方根）能量 + 频谱分析
- 自动标记歌曲中的高潮段落（时间区间）
- 数据缓存在内存中，切歌时自动加载

### 鼓点检测

- 基于 BPM（节拍）估算 + 能量峰值检测
- 区分强拍和弱拍
- 仅在高潮段落内启动鼓点检测

## 视觉效果

不同样式对高潮和鼓点的响应不同：

| 样式 | 高潮效果 | 鼓点效果 |
|------|----------|----------|
| 默认 | 背景色变化 | — |
| 舞台 | 文字变色 | 白色闪白（150ms 衰减） |
| 诡谲 | 关键词闪现 | 报纸滤镜 |
| 陈旧 | 光晕增强 | 脉冲 |
| 狂热 | 色彩饱和度增加 | 巨字缩放 |
| 雨夜 | 背景暗度变化 | 雨水强度增强 |

## 进度条标注

所有移动端播放器的进度条都会标注高潮段落：

- 高潮段落以高亮色块显示
- 当前播放位置在高潮段内时，色块高亮
- 点击进度条可跳转到指定时间

## 性能影响

高潮检测和鼓点检测使用 Web Audio API，对 CPU 有一定开销：

- 低端设备可能感到卡顿
- 可在设置中关闭高潮检测以节省电量
