# 本地音乐

播放设备本地存储的音乐文件。

## 添加本地音乐

1. 进入「本地音乐」页面
2. 点击「扫描本地音乐」
3. 选择要扫描的目录
4. 应用递归扫描目录中的音频文件

## 支持格式

| 格式 | 说明 |
|------|------|
| MP3 | 最常见格式 |
| FLAC | 无损压缩 |
| WAV | 无压缩 |
| OGG | 开源格式 |
| M4A / AAC | Apple 格式 |

## 功能

- **扫描** — 递归扫描目录，自动读取元数据（标题、歌手、专辑、封面）
- **播放** — 与在线音乐相同的播放体验
- **搜索** — 在本地音乐页面搜索本地歌曲
- **排序** — 按标题、歌手、专辑排序

## 存储

- 本地音乐索引缓存在 IndexedDB 中
- 切换扫描目录会重新扫描
- 不会修改或删除原始音乐文件

::: tip 提示
扫描大量文件可能需要较长时间，请耐心等待。
:::
