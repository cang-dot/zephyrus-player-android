# 自定义效果

每种播放器样式支持独立的效果参数调节。

## 使用方法

1. 在全屏播放器中点击右上角设置按钮
2. 选择一个非默认样式（如舞台、诡谲等）
3. 在「播放器样式」下方出现「自定义效果」面板
4. 调节滑块，改动实时生效并自动保存

## 各样式参数

### 舞台（Stage）

| 参数 | 说明 | 范围 |
|------|------|------|
| Aurora 速度 | 极光动画速度 | 0.4 ~ 2.0 |
| 鼓点闪白强度 | 闪白不透明度 | 0 ~ 1.0 |

### 诡谲（Eerie）

| 参数 | 说明 | 范围 |
|------|------|------|
| 报纸闪现频率 | 高潮关键词闪现间隔 | 200 ~ 1000ms |
| 关键词字号 | 高潮关键词字体大小 | 16 ~ 48px |

### 陈旧（Neon）

| 参数 | 说明 | 范围 |
|------|------|------|
| 光晕半径 | 文字光晕扩散范围 | 4 ~ 30px |
| 脉冲速度 | 鼓点时光晕脉冲速度 | 0.5 ~ 3.0 |

### 狂热（Frenzy）

| 参数 | 说明 | 范围 |
|------|------|------|
| 巨字字号 | 歌词字体大小 | 40 ~ 120px |

### 杂志（Magazine）

| 参数 | 说明 | 范围 |
|------|------|------|
| 翻页速度 | 歌词切换动画速度 | 200 ~ 800ms |

### 雨夜（Rain）

雨夜样式的参数在 LyricSettings 中配置，包括：

- 歌词模式（split / group）
- 显示封面
- 背景暗度
- 雨水强度 / 速度 / 颜色 / 透明度 / 角度 / 长度
- 音频响应

## 数据存储

配置存储在 `localStorage` 的 `music-full-config` 对象中的 `styleCustomConfig` 字段：

```json
{
  "playerStyle": "stage",
  "styleCustomConfig": {
    "stage": { "auroraSpeed": 1.2, "beatFlashIntensity": 0.5 },
    "eerie": { "newspaperFreq": 400, "keywordSize": 28 }
  }
}
```

切换样式时自动加载对应样式的配置。
