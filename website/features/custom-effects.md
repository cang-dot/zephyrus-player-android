# 自定义效果

每种移动播放器样式拥有独立的外观与高潮配置。进入全屏播放器，点击右上角设置按钮，在“播放器样式”中选择样式并切换到“自定义设置”即可调整。

## 通用外观

除默认播放器外，各样式均可独立保存背景、模糊、亮度、歌词颜色、字体和字重。大字样式还支持“强制不换行”，启用后中央歌词保持单行并允许向屏幕两侧溢出。

高潮配色有三层：

1. 关闭主题色跟随时，继续使用样式默认色或基础歌词色。
2. 开启主题色跟随时，主歌词与背景声部使用歌曲主题色。
3. 开启部件独立配色后，主歌词、背景或对唱、翻译可分别选择歌曲主题色或自定义色。

## 高潮效果

| 样式 | 可选效果                      | 组合规则             |
| ---- | ----------------------------- | -------------------- |
| 舞台 | 歌词变色、逐字砸下、错落      | 可组合               |
| 狂热 | CRT、歌词变色、逐字砸下、错落 | 可组合               |
| 诡谲 | 重点字、逐字砸下、错落        | 重点字与逐字砸下互斥 |
| 烟雾 | 继承诡谲效果、暗角、响度响应  | 重点字与逐字砸下互斥 |

逐字砸下和错落效果需要 TTML、YRC 或 QRC 的逐字时间。TTML 额外支持背景词和对唱词；接口歌词不会伪造声部。

## 烟雾参数

烟雾样式使用低分辨率 WebGL 流体模拟，高饱和歌曲主题色驱动烟雾颜色。可调整密度、混乱度、透明度、响度响应、字体横向拉伸和高潮暗角。WebGL 不可用或系统开启减少动态效果时会自动降级。

## 恢复默认

“一键还原”只删除当前样式的配置并恢复其内置默认，不影响其他样式。所有配置保存在 `music-full-config.styleCustomConfig[styleKey]`。
