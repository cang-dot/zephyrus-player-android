# 酷我音乐 Cookie 获取

获取酷我音乐 Cookie 可以在跨平台搜索中获取酷我音源的歌曲。

## 方法一：浏览器开发者工具

### 步骤

1. 在电脑浏览器打开 [kuwo.cn](https://www.kuwo.cn)
2. 登录你的酷我音乐账号
3. 按 `F12` 打开开发者工具
4. 切换到 **Application** 标签页
5. 左侧 **Cookies** → `https://www.kuwo.cn`
6. 找到以下 Cookie：

| Cookie 字段 | 说明 |
|------------|------|
| `kuwocloud` | 鉴权令牌 |
| `uid` | 用户 ID |
| `token` | 登录令牌 |

7. 复制这些值

### 在应用中配置

1. 打开 **设置** → **网络**
2. 在酷我 Cookie 输入框中粘贴完整 Cookie 字符串
3. 保存

## 方法二：抓包

1. 手机打开酷我音乐 App，播放一首歌
2. 抓包捕获 `kuwo.cn` 或 `m.kuwo.cn` 的请求
3. 复制请求头中的 Cookie

::: warning 注意
酷我音乐的 URL 解析默认关闭（不稳定），如需启用请在设置中手动开启。
:::
