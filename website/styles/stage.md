# 舞台样式

沉浸式深色舞台风格。

## 视觉特点

- **背景**：纯深色底（`#1a1a1a`），高潮时不改变背景色，仅文字变色
- **歌词**：居中大字，中文使用思源宋体（Noto Serif SC）
- **鼓点闪白**：高潮时段检测鼓点，白色闪光 150ms 衰减
- **高潮**：歌词文字切换为主题色

## 可调参数

| 参数 | 说明 | 默认值 | 范围 |
|------|------|--------|------|
| Aurora 速度 | 极光动画速度 | 0.8 | 0.4 ~ 2.0 |
| 鼓点闪白强度 | 闪白不透明度 | 0.5 | 0 ~ 1.0 |

## 适用场景

现场感强、高潮段落突出的歌曲。
