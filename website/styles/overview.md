# 播放器样式总览

Zephyrus Player 提供 7 种全屏播放器样式，每种都有独特的视觉风格和歌词渲染方式。

## 样式一览

| 样式 | 特点 | 适合场景 |
|------|------|----------|
| [默认](./default) | 封面取色背景 + 逐字歌词 | 日常使用 |
| [舞台](./stage) | 深色背景 + 居中大字歌词 + 鼓点闪白 | 高潮强烈的歌曲 |
| [诡谲](./eerie) | 噪点底 + 书法字歌词 + 高潮关键词 | 艺术感强的歌曲 |
| [陈旧](./neon) | 混凝土底 + 霓虹描边字 | 复古风格 |
| [狂热](./frenzy) | 极简色块 + 巨字歌词分屏 | 节奏强烈的歌曲 |
| [杂志](./magazine) | 色块拼贴 + 期刊式歌词 | 设计感强 |
| [雨夜](./rain) | 3D封面 + 雨水效果 + 歌词叠加 | 氛围感强的歌曲 |

## 切换样式

1. 在全屏播放器中，点击右上角设置按钮
2. 在「播放器样式」区域选择样式
3. 点击即可切换

## 自定义效果

每种样式支持独立的效果参数调节：

- 字体导入（`.ttf` / `.otf`）
- 样式专属参数（Aurora 速度、光晕半径、巨字字号等）

详见 [自定义效果](/features/custom-effects) 和 [字体导入](/features/font-import)。

## 横竖屏适配

所有移动端样式均支持横竖屏自动切换：

- **竖屏** — 每种样式有独立的竖屏布局
- **横屏** — 与竖屏使用同一组件，通过 CSS 自适应

控件（进度条、按钮等）3 秒无操作自动隐藏。
