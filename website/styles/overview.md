# 播放器样式总览

Zephyrus Player v1.2.5 当前提供八种 Android 移动播放器样式。每种样式独立保存背景、歌词颜色、字体、字重和高潮效果，切换样式不会覆盖其他样式的配置。

| 样式 | 方向                   | 逐字能力           |
| ---- | ---------------------- | ------------------ |
| 默认 | 封面取色与居中滚动歌词 | TTML/YRC/QRC       |
| 舞台 | 巨幅歌词与背景声部     | 变色、砸下、错落   |
| 诡谲 | 噪点、拉伸与重点字     | 重点字或砸下       |
| 狂热 | 高对比、CRT 与冲击文字 | CRT、变色、砸下    |
| 陈旧 | 旧印刷和霓虹边缘       | 大字与单行溢出     |
| 雨夜 | 雨幕、反射和封面空间   | 音频响应           |
| 星盘 | 星轨和夜空层次         | 主歌词呼吸         |
| 烟雾 | WebGL 流体烟雾         | 响度响应、高潮暗角 |

## 原始设置与自定义设置

原始设置使用组件内置视觉和默认高潮组合。自定义设置开放纯色、渐变或图片背景、模糊、亮度、基础歌词色、字体、字重和效果开关。

“一键还原”只清除当前样式的配置。旧的全局外观字段不再控制 Android 移动播放器。

## 主题色

“高潮使用歌曲主题色”关闭时，样式继续使用默认色或自定义基础色。开启后可以统一跟随主题色，也可以让主歌词、背景/对唱和翻译分别选择跟随或自定义。

## 大字样式

舞台、诡谲、狂热、陈旧和烟雾支持“强制不换行”。开启后屏幕中央的大字合并到一行，并允许从左右边缘溢出。

舞台、诡谲、狂热和烟雾还共享 TTML 背景/对唱巨字与间奏尾奏状态。间奏尾奏不要求高潮，只要求当前 TTML 主句已经结束，并且下一句至少 15 秒后开始或已经没有后续主句。

## 减少动态效果

系统开启减少动态效果后，逐字砸下、流体烟雾、弹簧位移和强烈闪烁会降低幅度或改成淡入。歌词时间轴和交互功能不受影响。
