# 雨夜样式

3D 封面 + 雨水效果 + 歌词叠加的氛围风格。

## 视觉特点

### 竖屏

- **3D 封面**：居中显示，带透视倾斜效果（`rotateX(12deg)`）
- **淋雨暗化**：封面上有渐变暗化遮罩
- **歌词叠加**：歌词文字覆盖在封面上方
- **底部反射**：封面底部有轻微反射效果（模糊 + 渐变 mask）
- **雨水效果**：Canvas 雨滴动画，音频响应

### 横屏

- **左右分词歌词**：当前句在左侧，下一句在右侧
- **中间封面**：`CoverRipple` 组件，带涟漪效果

## 可调参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 歌词模式 | split（分词）/ group（两句一组） | split |
| 显示封面 | 是否显示封面 | 开 |
| 背景暗度 | 背景暗化程度 | 70 |
| 雨水强度 | 雨滴密度 | 50 |
| 雨水速度 | 雨滴下落速度 | 1 |
| 音频响应 | 雨水随音频变化 | 开 |
| 雨水颜色 | 雨滴颜色 | #ffffff |
| 雨水透明度 | 雨滴不透明度 | 0.6 |
| 雨水角度 | 雨滴倾斜角度 | 15° |
| 雨水长度 | 雨滴线条长度 | 40px |

## 适用场景

氛围感强、雨天场景、Lo-fi、R&B、民谣。
