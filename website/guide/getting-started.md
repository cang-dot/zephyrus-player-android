# 基本使用

## 首页

登录后进入首页，首页包含以下内容：

- **每日推荐** — 每日更新的歌曲推荐
- **新专辑** — 最新发行的专辑
- **推荐歌单** — 根据你的喜好推荐歌单
- **热门歌手** — 热门音乐人

## 搜索

点击底部搜索标签进入搜索页面：

1. 在搜索框输入关键词
2. 选择搜索类型（单曲 / 专辑 / 歌单 / MV）
3. 点击搜索按钮
4. 搜索结果自动加载网易云结果，同时异步搜索其他音源

::: tip 跨平台搜索
搜索单曲时，应用会自动搜索 QQ音乐、咪咕、酷狗、酷我等平台，并将结果合并去重。
每首歌会标注来源（网易云 / JOOX / QQ 等），可点击筛选。
详见 [跨平台搜索](/features/cross-platform-search)。
:::

## 播放音乐

### 点击播放

在搜索结果、歌单、专辑等列表中，点击歌曲即可播放。

### 播放控制

播放时底部显示迷你播放栏，点击可进入全屏播放器。

全屏播放器操作：

| 操作 | 效果 |
|------|------|
| **单击屏幕** | 切换控件显隐 |
| **双击屏幕** | 进入滚动歌词模式 |
| **拖动进度条** | 跳转到指定时间 |
| **点击歌词文字** | 跳转到该句歌词的时间 |

### 控件说明

- 左上角：关闭全屏播放器
- 右上角：播放设置
- 底部：进度条 + 高潮标注 + 播放/暂停/上一首/下一首/播放列表

## 播放列表

点击播放列表按钮（右下角）打开当前播放队列抽屉。

- 可拖动歌曲调整顺序
- 点击歌曲切换播放
- 左滑删除歌曲

## 歌单管理

- **创建歌单** — 我的 → 创建歌单
- **导入歌单** — 我的 → 导入歌单（粘贴网易云歌单链接）
- **收藏歌单** — 在歌单详情页点击收藏

## 下载

在歌曲列表中，点击歌曲右侧的更多按钮 → 下载。下载的歌曲保存在本地，可在「本地音乐」页面查看。

详见 [本地音乐](/features/local-music)。
