# Zephyrus Player 横版工具推荐视频方案

> 本文件是早期平稳节奏方案。当前审核稿为 [Zephyrus横版实测快剪审核方案.md](./Zephyrus横版实测快剪审核方案.md)。

## 视频定位

这是一支约 90 秒的横版工具推荐视频，不按品牌广告片处理。视频由口播带着观众查看界面，先说明这款播放器有什么特别，再演示逐字歌词、播放器样式、多平台搜索、本地音乐和状态栏歌词。结尾说明安装条件、使用限制和适合人群。

成片规格：16:9 横版，1920×1080，30 fps，约 90 秒。

推荐标题：

- Android 上的逐字歌词播放器：Zephyrus Player
- 喜欢逐字歌词，可以看看 Zephyrus Player
- Zephyrus Player：逐字歌词、九种样式和状态栏歌词

封面文字：**Android 逐字歌词播放器**

## 90 秒口播稿

如果你用 Android 听歌，而且很在意歌词显示，可以看看 Zephyrus Player。这是一款开源播放器，主打逐字歌词。

播放歌曲后，它会依次查找 TTML、YRC、QRC 和 LRC。找到逐字歌词时，每个字都会跟着进度变化；背景声部、对唱、翻译和罗马音也能一起显示。只有普通 LRC 时，就按整句滚动。

播放器有九种样式。舞台、雨夜、烟雾的排版和动效差别很大，每种样式还能分别保存背景、歌词颜色、字体和高潮效果。

找歌时，可以查看多个平台的结果，再按来源筛选。不过能否播放，还要看账号、接口和网络状态。

它也支持本地歌曲，常见音频和 LRC、YRC、TTML 等歌词文件都可以扫描。

允许悬浮窗权限后，切到别的应用，歌词还会显示在状态栏，位置、字体和颜色都能调整。

如果你经常看歌词、有自己的本地曲库，或者喜欢调整播放器外观，这款会比较合适。只需要基础播放的话，里面不少设置可能用不到。

Android 8.0 及以上可以安装 APK，源码和下载地址放在简介里。

## 画面节奏

- 以真实操作和界面变化为主，少用全屏口号和长时间空镜。
- 每个功能先出现操作，再由口播解释结果。鼠标指针、点击反馈和局部放大可以帮助观众跟上操作。
- 画面每 4 到 7 秒出现一次明确变化，例如切换标签、歌词推进、列表扫描或样式放大。
- 转场使用普通硬切、轻微推近和位置匹配。原方案中的 3D 环绕只保留在开场 2 秒，不再作为主要表现方式。
- 字幕按正常说话节奏断句，每行不超过 18 个中文字符。技术格式名单独使用小标签显示，不全部塞进口播字幕。

## 推荐视频与广告片的区别

| 项目 | 本方案处理方式 |
| --- | --- |
| 开场 | 第一秒就说明它是什么、适合谁，不先播放品牌动画。 |
| 口吻 | 像在介绍一个工具，允许说明限制，不使用“重新定义”“极致体验”等广告词。 |
| 画面 | 操作过程比氛围镜头重要，标注跟着操作出现。 |
| 功能 | 每项功能说明“怎么用、结果是什么”，不只展示功能名称。 |
| 结尾 | 给出适合人群、安装条件和下载位置，不做口号式升华。 |

## 信息边界

- 当前项目版本为 1.2.5，发布目标是 Android 手机，要求 Android 8.0 或更高版本。
- 多平台搜索和播放结果会受到账号、来源接口和网络状态影响，视频中必须保留提示。
- 状态栏歌词依赖悬浮窗权限。普通 LRC 按整句显示，TTML 的背景声部和对唱只在应用内播放器中展示。
- 本地音频支持 MP3、FLAC、M4A、OGG 和 Opus；项目说明中的部分历史材料还出现过 WAV，成片口播以 README 当前列出的格式为准。
- UI 中的歌曲名、歌手和歌词均使用合成内容，避免使用未经授权的封面、音乐和完整歌词。
