# Zephyrus Player 横版宣传片方案

> 本文件是早期品牌宣传片方案。当前应使用 [Zephyrus横版工具推荐视频方案.md](./Zephyrus横版工具推荐视频方案.md)。

## 项目简介

Zephyrus Player（西风播放器）是一款为 Android 手机开发的音乐播放器。它支持逐字歌词、九种播放器样式、跨平台搜索、本地音乐和状态栏歌词。应用会依次查找 Zephyrus TTML、AMLL TTML、网易云 YRC、QQ QRC 和普通 LRC。TTML 可以保留主唱、背景声部、对唱、翻译和罗马音；找不到逐字歌词时，播放器会改用普通 LRC，按整句滚动。

这支宣传片面向重视歌词同步、播放器样式、本地曲库和 Android 状态栏歌词的用户。

核心文案：**让音乐响起，也让歌词跟上。**

成片规格：16:9 横版，1920×1080，30 fps，约 60 秒。

## 60 秒口播稿

点下播放，音乐响起。

Zephyrus Player 还会把歌词的变化，一字一句显示出来。

它会按顺序查找 TTML、YRC、QRC 和 LRC。主唱、背景声部、对唱、翻译和罗马音，都跟着播放进度同步。只有普通 LRC 时，就按整句滚动。

搜索结果来自多个音乐平台，还可以按来源筛选。本地歌曲和歌词文件，也能一起扫描进曲库。

播放器有九种样式。每一种都能单独设置背景、歌词颜色、字体、字重和高潮效果。

允许悬浮窗权限后，状态栏也会继续显示歌词。位置、字体、逐字方式和颜色，都可以自己调整。

Zephyrus Player，只为 Android 手机设计。让音乐响起，也让歌词跟上。

## 制作参数

### 摄影机与三维 UI

- 软件界面作为静态平面或 2.5D 分层对象，禁止让产品自行旋转、缩放或漂浮抖动。
- Hero 镜头由相机沿 Y 轴轨迹移动，UI 角度变化完全来自相机位移。
- 三层最小景深：前景边框距 UI 20-35px，中景 UI，背景网格距 UI 80-120px。
- 相机运动速度控制在常速的 70%-80%，曲线使用 `cubic-bezier(0.22, 1, 0.36, 1)`。

### 字体与字幕

- 中文章节标题：思源黑体 Heavy、苹方-简 Heavy 或等价无衬线重黑体。
- 正文字体：思源黑体 / 苹方，Medium 或 Semibold。
- 英文：SF Pro Display / Inter。
- 字幕安全区：左右 110px，上下 64px；单行尽量不超过 18 个中文字符。
- 全屏章节标题入场和退场均为 0.3 秒 Ease In-Out，停留至少 1.5 秒。

### 颜色与调色

- 背景：`#090B09`。
- 主文字：`#F2F7F0`。
- 强调色仅三种：荧光绿 `#B9F78B`、珊瑚红 `#FF785C`、青色 `#7EDBCE`。
- UI 玻璃层背景模糊不低于 20px；保留 1px 高光边和轻微内阴影。
- 不使用额外渐变色、镜头光斑、彩色环境球或专辑封面。

### 音轨结构

- 00:00-00:10：稀疏钢琴与低噪底，预留品牌呼吸。
- 00:10-00:35：加入低频脉冲和细碎节拍，UI 点击与歌词推进对齐。
- 00:35-00:45：完整鼓组进入，集中展示九种播放器样式。
- 00:45-00:54：鼓组减半，突出系统提示与状态栏歌词。
- 00:54-01:00：抽掉节奏，仅保留一个和弦、品牌尾响和口播。

### 导出

- 主版：H.264 High Profile，1920×1080，30 fps，20-30 Mbps，AAC 48kHz 320kbps。
- 母版：ProRes 422 HQ 或 DNxHR HQX，48kHz/24bit PCM。
- 字幕：额外输出烧录字幕版与无字幕净版；另交 SRT。

## 真实性边界

- “九种样式”依据当前 Android 样式注册：默认、舞台、诡谲、狂热、陈旧、杂志、雨夜、星盘、烟雾。
- “多源搜索”画面是功能示意；实际可用结果取决于用户账号、来源接口和网络状态。
- 状态栏歌词需要 Android 悬浮窗权限；普通 LRC 会退化为整句显示。
- 本地音乐支持格式以项目当前说明为准；宣传片不承诺所有编码组合都可播放。
