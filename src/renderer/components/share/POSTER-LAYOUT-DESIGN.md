# Poster Layout Structure

## Performance Archive

```text
+--------------------------------+
| desaturated / monochrome cover |
|                                |
|  oversized accent brush title  |
|                                |
| artist                  date   |
| venue / archive label           |
+--------------------------------+
| large selected lyric lines      |
|                                |
| watermark                 QR    |
+--------------------------------+
```

The cover occupies the upper image field. A fade connects it to the black lyric field. The title
uses the configurable display font, weight, accent color, and horizontal, vertical, or staggered
orientation. Artist, venue, and date form a compact archival metadata row.

## Seal Tour

```text
+----------------------+---------+
| high-contrast image  | vertical|
|                      | title   |
|                (artist seal)   |
+--------------------------------+
| date / venue / event label      |
| selected lyric excerpt          |
| watermark                 QR    |
+--------------------------------+
```

The image and vertical title intentionally overlap at the boundary. A configurable accent-color
seal anchors artist identity. The lower register behaves like a tour schedule with strong rules,
then finishes with a short lyric excerpt.
